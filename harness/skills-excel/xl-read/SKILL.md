# xl-read（读取分析）

## 适用

- 用户给了一个 Excel 文件路径，想了解内容/结构/数据概况
- 需要分析文件再决定下一步操作（清洗/转换/合并）
- 用户问"这个表里有什么""帮我看看这个文件"

## 步骤

1. **直接跑预置脚本，不要自写分析代码**：

   ```bash
   {{PYTHON_CMD}} {{BUILTIN_SKILLS_DIR}}/xlsx/scripts/xl_summarize.py "<文件>"
   ```

   一条命令返回 JSON：每个 sheet 的 `rows/cols/sampled/columns（类型/非空/空值占比/数值 min-max-mean/object 唯一值与 Top5）/preview（前 5 行）/note`。`.csv`/`.tsv` 按单表处理，编码自动兜底（utf-8-sig → gbk → gb18030）。

2. 可调参数（按需追加）：`--sample N` 大文件采样行数（默认 1000）、`--limit N` 全量统计阈值（默认 50000）。

3. 把 JSON 整理成中文摘要给用户，不要原样贴 JSON。

4. 只有需要更深信息（如公式字符串/缓存值、openpyxl 才暴露的合并单元格等）时才自写脚本，且遵守内置 `xlsx` 技能的读取 gotcha（两趟读取、`data_only=True` 破坏性等）。

## 行数口径（汇报时必须遵守）

- 数据行 ≤ 50,000：全量加载，`rows` 为真实数据行数，统计即全量口径。
- 数据行 > 50,000：只读前 1,000 行做统计与预览，`rows` 用 openpyxl `max_row-1` 估算（**可能含格式空行**）。此时汇报要标注"≈"与"基于前 1,000 行采样"，**不要把采样统计当全量结论**。
- `note` 字段会自带口径说明，照实转述即可。

## 输出格式

用中文摘要呈现，格式：

**文件：<路径>**

| Sheet | 行数 | 列数 |
| --- | --- | --- |
| Sheet1 | 1,234 | 12 |

> 行数口径：<50,000 行为实际数据行数；≥50,000 行标注"≈"（openpyxl 估算），此时列统计注明"基于前 1,000 行采样"。

**Sheet1 列信息：**

| 列名 | 类型 | 非空率 | 说明 |
| --- | --- | --- | --- |
| 订单号 | str | 100% | 唯一值 1,234 个 |
| 金额 | float64 | 98.5% | 范围 0~125,000 |
| 日期 | str | 100% | — |

**数据预览（前 5 行）：**
（markdown 表格）

**建议下一步：** 去重 / 清洗空值 / 格式转换 / 合并其他表 …

## 故障排查

- 提示"文件不存在" → 先确认路径与授权目录，再跑。
- 提示缺 pandas/openpyxl → Excel 环境未补全，引导用户去设置页「补全 Excel 环境」。
