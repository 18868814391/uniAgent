# pm-prototype（原型设计）

## 适用

- 需求已澄清/有大致方向，需要设计页面结构与交互。
- 用户要求"设计原型 / 设计页面 / 画一下这个功能长什么样"。

## 步骤

1. **先对齐代码**：运行 `pm-code-align` 技能，找到同类既有页面，提取 UI 元素与字段。
2. **组织页面**：列出页面清单与进入路径（从哪个菜单/路由进入），标注每页职责。
3. **逐页设计**：每页产出 SVG 线框图（`pm-svg` 规范）+ 关键交互说明。
4. **字段逻辑**：每页附字段逻辑表（`pm-field-logic` 规范）。
5. **状态与反馈**：列出加载/空态/异常/成功/失败/无权限的反馈。
6. **落盘**：写成 `.md`，写入 `{{PRODUCT_OUTPUT_DIR}}/work/<任务slug>/<页面名>-原型设计.md`。

## 设计原则

- **复用**：对齐既有页面的布局、组件、交互，新原型是"在已有体系里长出新的功能"，不是换个全新风格。
- **分层**：搜索区 / 工具栏 / 表格 / 分页结构清晰；表单必填标注；操作有确认与反馈。
- **完整**：关键状态（空态、无权限、审核中）都要画出来，不要只画主路径。

## 输出示例结构

```markdown

## 二、页面结构

| 新增弹窗 | 列表页"新增"按钮 | 录入与保存 |
## 三、UI 对齐说明
## 四、页面原型
### 页面1：列表页
<SVG 线框图>
关键交互：筛选→刷新列表；新增→弹窗；行操作→编辑/删除
## 五、字段逻辑表
## 六、交互与状态反馈
## 七、待确认项
```
